# Founder-only StudyFlow research pilot

The optional panel appears in the Atlas learning context for game-development, web-development and ai-automation only, after the existing server-verified founder entitlement resolves, and only when `VITE_ATLAS_CURATED_RESEARCH_ENABLED=true`. The server endpoint additionally requires `ATLAS_CURATED_RESEARCH_ENABLED=true` and validates the authenticated founder independently. Neither flag is enabled by this patch. The endpoint currently permits only the two production origins; do not weaken CORS or enable production to test a preview. Test with local mocked requests first; explicitly approve a controlled deployment/origin before end-to-end testing.

The user supplies device/software assumptions and self-reported artifact prerequisites. The panel returns only manually reviewed Unity 6.0, MDN HTML/CSS and Python 3.14 documentation, not live searches, and drafts a StudyFlow prompt on explicit click. No saved roadmap schema or mastery status changes. Sending the draft still follows the existing AI pause and metering flow. No database migration or paid API is needed. Resource durations are estimates. No matching results may mean stale review or incompatible prerequisites, not that no resources exist online.

The frontend binds each known catalogue ID to its exact official URL. New entries require a coordinated update to this allowlist. Python is a small introductory resource for AI & Automation, not an entire automation curriculum. All prerequisites remain self-reported.
