# Founder-only StudyFlow research pilot

The optional panel appears in the Atlas learning context for game-development only, after the existing server-verified founder entitlement resolves, and only when `VITE_ATLAS_CURATED_RESEARCH_ENABLED=true`. The server endpoint additionally requires `ATLAS_CURATED_RESEARCH_ENABLED=true` and validates the authenticated founder independently. Neither flag is enabled by this patch. The endpoint currently permits only the two production origins; do not weaken CORS or enable production to test a preview. Test with local mocked requests first; explicitly approve a controlled deployment/origin before end-to-end testing.

The user supplies device/software assumptions and self-reported artifact prerequisites. The panel returns only manually reviewed Unity documentation, not live searches, and drafts a StudyFlow prompt on explicit click. No saved roadmap schema or mastery status changes. Sending the draft still follows the existing AI pause and metering flow. No database migration or paid API is needed. Resource durations are estimates. No matching results may mean stale review or incompatible prerequisites, not that no resources exist online.
